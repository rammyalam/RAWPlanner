Workout Planner PWA V1.2

IMPORTANT: This folder is named WorkoutPlannerPWA-V1.2 so it cannot be confused with V1.

Run on Windows:
1. Stop the old Python server with Ctrl+C.
2. Extract this ZIP.
3. Open PowerShell.
4. cd into the extracted WorkoutPlannerPWA-V1.2 folder.
5. Run: python -m http.server 8080
6. Open: http://localhost:8080
7. The subtitle MUST say: Personal training • local & private • V1.2

V1.2 workout screen verification:
- Every exercise has Swap and Remove buttons.
- Core exercises have reps fields only (no weight fields).
- Common bodyweight movements have reps fields only.
- There is no "Suggested: choose starting weight" wording.
- Previous performance appears only when that exercise has prior history.

If the subtitle does not say V1.2, you are still running the old folder or browser cache.
